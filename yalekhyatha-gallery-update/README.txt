YALEKHYATHA GALLERY UPDATE

This package contains the updated index.html and the 29 gallery photos.

To update GitHub:
1. Replace your current index.html with this index.html.
2. Upload the entire images folder to the repository root.
3. Keep the folder name exactly: images
4. Wait for GitHub Pages to redeploy.
5. Open https://jenyyalekhyatha.ca/

The gallery filters include:
- All
- Flags
- Colours: Black, Teal, Blue, Red, Pink, White, Gold

The photos are stored locally in the images folder so they do not depend on Facebook image URLs.
